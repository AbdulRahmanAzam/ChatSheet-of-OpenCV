1. You run cv2.HoughCircles(gray, cv2.HOUGH_GRADIENT, dp=1.2, minDist=40, param1=120, param2=30, minRadius=10, maxRadius=60). Which statement is most accurate?
A) Every circle in the image is always detected
B) A circle is returned only if its center gets enough votes and its radius is between 10 and 60
C) Only circles with radius exactly 60 are returned
D) The function returns rectangles around circles
Correct Answer: B

2. edges = cv2.Canny(blur, 50, 150). Which statement is most accurate?
A) Pixels with gradient above 150 are strong edges, and pixels between 50 and 150 are kept only if connected to strong edges
B) Only pixels with gradient exactly 150 become edges
C) All pixels above 50 are always kept as edges
D) Canny returns a color image
Correct Answer: A

3. You apply Otsu thresholding to an image with a bimodal histogram. Which statement is most accurate?
A) Otsu always gives the best result for every image
B) The threshold value 0 passed to the function is used exactly as given
C) Otsu chooses the threshold that best separates the two intensity groups
D) Otsu works only on color images
Correct Answer: C

4. You match SIFT descriptors with knnMatch(k=2) and apply the ratio test with 0.75. Which statement is most accurate?
A) All matches are always kept
B) A match is kept when the best distance is clearly smaller than the second-best distance
C) Only matches with distance exactly 0.75 are kept
D) The ratio test converts keypoints into contours

5. contours, _ = cv2.findContours(mask, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE). Which statement is most accurate?

6. You call cv2.findHomography(src, dst, cv2.RANSAC, 5.0) with 50 matches, some of them wrong. Which statement is most accurate?
