6.1.1.4 The solution: Homogenous Coordinates
Homogeneous coordinates bypass the origin limitation by adding a
temporary, dummy "1" to standard 2D coordinates, turning (x, y) into
(x, y, 1). This mathematical trick allows computers to perform
translations using only matrix multiplication, completely eliminating
the need for a separate vector addition step.
The Problem with Vector Addition
The standard affine equation is
p' = Ap + b
This forces the computer to perform a matrix multiplication (Ap) for
scaling or rotating, stop that process, and then perform a separate
vector addition (+b) to slide the object. Graphics processors (GPUs)
are deeply optimized to execute continuous, uninterrupted chains of
matrix multiplications. Breaking that hardware pipeline to switch to
vector addition creates a massive computational bottleneck when
calculating millions of coordinate points per second.
The Matrix Multiplication Solution
By upgrading the math to a 3 x 3 matrix, we can fold the translation
values tx and ty directly into the rightmost column:

forces the "1" in the coordinate vector to multiply against the tx and

The Power of Composition
Because translation, rotation, and scaling are now aLL formatted
uniformly as 3 x 3 matrix multiplications, they speak the exact same
mathematical language. A computer can multiply a scale matrix, a
rotation matrix, and a translation matrix together into one single
"master matrix" before touching the geometry. The graphics engine then
only has to perform one single matrix multiplication per pixel to
apply all three transformations simultaneously.

6.2.2 The Denominator Effect
The denominator h31X + h32Y + is the critical mathematical distinction
between affine and projective geometry .
In an affine transformation, the bottom row of the matrix is strictly
locked to [O, @ , 1] . Therefore, the denominator is always exactly 1,
causing uniform scaling across the entire image.
In a projective transformation, the denominator fluctuates depending
on the x and y values of the specific point being processed. As points
"move further away" in the virtual space, the denominator grows
larger, causing the resulting x' and y' coordinates to shrink closer
together. This variable division is the mathematical engine that
generates depth.
